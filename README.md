## AI Caregiver Assistant for Stroke Patients

AI Caregiver Assistant adalah platform berbasis web yang dirancang khusus untuk membantu *caregiver* (perawat/pendamping) dalam memantau, mencatat, dan menganalisis perkembangan pasien pasca-stroke. Dengan dukungan kecerdasan buatan (AI), aplikasi ini mempermudah proses pemantauan gejala harian, tanda-tanda vital, serta memberikan rekomendasi pemulihan.

## 🚀 Fitur Utama

Sistem ini memiliki dua peran pengguna utama, yaitu **Caregiver** dan **Admin**, dengan fungsionalitas sebagai berikut:

### 🧑‍⚕️ Fitur untuk Caregiver
Caregiver dapat menggunakan aplikasi ini untuk manajemen pasien sehari-hari:
- **Autentikasi Akun**: Registrasi, Login, dan Reset Password.
- **Manajemen Data Pasien**: Menambah dan menghapus data pasien stroke yang dirawat.
- **Pemantauan Kesehatan**:
  - Menginput Data Vital Pasien.
  - Menginput Observasi Gejala Pasien.
  - Menginput Skor Prognosis.
- **Pencatatan Harian**: Mengisi dan melihat Jurnal Harian terkait kondisi pasien.
- **Riwayat & Progres**: Memantau riwayat kesehatan dan progres pemulihan pasien.
- **AI ChatBot**: Mengajukan pertanyaan ke AI ChatBot untuk mendapatkan interpretasi, saran, dan rekomendasi perawatan. (ini next time aja baru dibuat)
